# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be welcoming and patient, assume good intent, keep criticism about the work and not the person, and
do not harass anyone. This applies in issues, pull requests, discussions and anywhere you represent the project.

Unacceptable behaviour can be reported to the maintainer through
[a private security advisory](https://github.com/nabrahma/RealIndex/security/advisories/new) if it cannot be
raised in public. Reports are handled confidentially. The maintainer may remove comments, close threads or block
accounts that break these standards.
